# AetherGrid-AI

### Autonomous Logistics and Emergency Dispatch Simulation

AetherGrid AI is a simulation-based intelligent dispatch system that
optimizes the routing and assignment of emergency and logistics
vehicles in a dynamic urban environment.

The system considers changing traffic, road closures, hazards, weather,
vehicle availability, and incoming requests.

## Key Features

- Dynamic route planning using A*
- Shortest-path computation using Dijkstra
- Vehicle-request assignment using the Hungarian Algorithm
- Multi-stop logistics optimization using Genetic Algorithms
- Idle-vehicle repositioning using Reinforcement Learning
- Dynamic traffic, hazards, weather, and road closures
- Real-time simulation and visualization
- Reproducible experiments and performance evaluation
